# 🤖 ربات تبلیغ محصولات برای ایتا و تلگرام

یک ربات ساده که محصولات شما را در کانال ایتا یا تلگرام تبلیغ می‌کند.

---

## 🎯 این ربات چه کاری انجام می‌دهد؟

- محصولات را از دیتابیس می‌خواند
- هر محصول را به صورت یک پیام تبلیغاتی ارسال می‌کند
- می‌تواند هر چند ساعت یکبار خودکار اجرا شود
- آمار بازدید و کلیک محصولات را ذخیره می‌کند

---

## 📋 نیازمندی‌ها

- PHP 7.4 یا بالاتر
- MySQL
- یک ربات در ایتا یا تلگرام (توکن از @BotFather بگیر)

---

## 🚀 نصب سریع (۳ مرحله)

## نصب و اجرا (به ترتیب)

```bash
# 1. دانلود
git clone https://github.com/yourusername/product-bot.git
cd product-bot

# 2. تنظیمات
cp config.example.php config.php
# حالا فایل config.php را باز کن و توکن ربات را وارد کن

# 3. نصب دیتابیس (فقط یکبار)
php install.php

# 4. اجرای ربات
php bot.php
